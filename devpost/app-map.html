SprintClarify Architecture Map

A reference guide to how SprintClarify transforms ambiguous product requests into verified Agile backlogs using Gemini structured output schemas.

How the System Works

SprintClarify is a serverless Single Page Application (React + Vite) that communicates directly with the Google Gemini API. It enforces strict JSON output schemas via the Google Gen AI SDK (responseSchema), instantly rendering Jira-ready backlogs and visual Mermaid dependency sequences without conversational fluff.

Reference Code Route

To inspect or extend the core decomposition flow, follow these key architectural stops:

01
Data Contract Definition

src/types/agile.ts — Defines DecompositionResult, Epic, and UserStory interfaces with strict Gherkin criteria arrays and prerequisite/blocking dependencies.

02
Structured Gemini Schema Engine

src/lib/gemini.ts (symbol: agileDecompositionSchema) — Maps the TypeScript types into Google Gen AI SDK Type.OBJECT and Type.ARRAY definitions, calling ai.models.generateContent with responseMimeType: "application/json".

03
Interactive Card Rendering & Jira Export

src/components/StoryCard.tsx & src/lib/markdownExporter.ts — Manages accordion collapsing, renders emerald Gherkin checks and amber risk tags, and formats tickets into 1-click clipboard Markdown.

04
Visual Sequence Execution Flow

src/components/MermaidVisualizer.tsx — Encapsulates dynamic mermaid.render() with dark theme variables and syntax fallback guards.

To Change This, Start Here

Add New Starter Prompts Edit src/lib/starterPrompts.ts to add prompt pills tailored to your domain.
Modify Agile Schema Fields Update src/types/agile.ts and sync the schema inside src/lib/gemini.ts.
Adjust Markdown Export Format Tweak formatStoryMarkdown in src/lib/markdownExporter.ts for custom ticket layouts.
Change Visual Theme & Colors Adjust tailwind.config.js or CSS classes in src/index.css.

A Practice to Reuse: Spec-Driven Structured Schemas

The Practice: Instead of asking an LLM for conversational advice and spending human time reformatting the text, define a strict schema contract (responseSchema) upfront in types.

Why it works: Gemini 3.8 Flash guarantees deterministic JSON structure adhering to the exact schema. This allows frontend components to render immediately with zero parsing regexes, eliminates conversational fluff, and guarantees that every ticket has required fields (ID, title, Gherkin criteria, and risk flags).
